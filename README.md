# News Scraper

A Python project that scrapes news headlines from websites and displays them.

## Features
- Scrapes latest news headlines from multiple sources
- Stores headlines with timestamp
- Can be extended to save in CSV or database
- Simple and easy to use

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/AKSHARA123-UI/News_scraper.git
```
